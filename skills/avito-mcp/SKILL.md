# Авито через MCP

Ставит сервер `avito-mcp-ru`: 64 метода официального API
(чтение 40, запись 22, необратимое 2). Каталог методов лежит в YAML и
исполняется сервером, поэтому агент получает несколько универсальных
инструментов, а не по отдельной функции на каждый метод.

## Установка

Первый релиз на PyPI выпускается тегом `v0.5.3`, до этого пакет ставится прямо из репозитория:

```bash
uvx --from git+https://github.com/ilyautov/avito-mcp-ru avito-mcp-ru
```

После релиза строка короче:

```bash
uvx avito-mcp-ru
```

Конфигурация клиента (Claude Desktop, Cursor, Claude Code):

```json
{
  "mcpServers": {
    "avito": {
      "command": "uvx",
      "args": ["--from", "git+https://github.com/ilyautov/avito-mcp-ru", "avito-mcp-ru"],
      "env": {
        "AVITO_CLIENT_ID": "<значение>",
        "AVITO_CLIENT_SECRET": "<значение>"
      }
    }
  }
}
```

## Где взять ключи

- `AVITO_CLIENT_ID`: client_id из раздела Для бизнеса → Интеграции → API.
- `AVITO_CLIENT_SECRET`: client_secret оттуда же, меняется на токен по OAuth2.

Второй путь, без переменных окружения: поднять сервер и вызвать
`avito_add_cabinet`. Ключи лягут в `~/.marketplace-mcp/cabinets.json`
с правами 600 и с машины не уходят. Так же подключается второй магазин.

## Что спрашивать у сервера

- `avito_search_methods("остатки по складам")`: поиск метода словами.
- `avito_describe_method(...)`: параметры, пагинация, класс доступа.
- `avito_call_method(...)`: вызов. Чтение идёт сразу, запись просит
  подтверждения, необратимое просит дважды.
- `avito_check_auth`: проверить, что ключи дошли.

## Как себя вести

Сначала ищи метод каталогом, не угадывай имя. Перед записью покажи человеку,
что именно уйдёт в API, и дождись согласия: гейт сработает всё равно, но
человек должен увидеть тело запроса до, а не после.

Числа из ответа не округляй и не пересчитывай в уме. Если метод вернул
пустой список, так и скажи, вместо того чтобы объяснять это за продавца.
